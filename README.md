# 🍽️ ZestHub

**Where Great Food Begins**

ZestHub is a full-stack Restaurant Discovery and Review Platform that helps users discover restaurants, explore menus, read reviews, and save their favorite places.

## 📌 Project Overview

ZestHub provides a modern platform where users can search for restaurants, browse menus, rate their dining experiences, and manage their favorite restaurants. Restaurant owners can manage their restaurant information and menu items, while administrators oversee the entire platform.

## 🚀 Features

* User Authentication
* Restaurant Discovery
* Restaurant Search & Filters
* Menu Management
* Ratings & Reviews
* Favorite Restaurants
* Responsive User Interface
* Admin Dashboard
* Restaurant Owner Dashboard
* AI-based Restaurant Recommendation (Future Enhancement)
